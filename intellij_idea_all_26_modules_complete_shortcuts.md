# IntelliJ IDEA Complete Shortcut Reference — All 26 Modules

This shortcut guide follows the **IntelliJ IDEA Zero to Hero course** module by module.

> **Note:** Shortcuts can vary depending on your IntelliJ keymap, operating system, keyboard layout, and whether you use macOS, Windows, or Linux.  
> When a shortcut does not work, use **Find Action**:
>
> - **Mac:** `Cmd + Shift + A`
> - **Windows/Linux:** `Ctrl + Shift + A`

# Recommended Learning Order

Memorize shortcuts in this order:

1. `Shift Shift` — Search Everywhere  
2. `Cmd/Ctrl + Shift + A` — Find Action  
3. `Cmd/Ctrl + E` — Recent Files  
4. `Option/Alt + Enter` — Quick Fix  
5. `Cmd/Ctrl + Option/Alt + L` — Reformat Code  
6. `Shift + F6` — Rename  
7. `Option/Alt + F7` — Find Usages  
8. `Ctrl + R` / `Shift + F10` — Run  
9. `Ctrl + D` / `Shift + F9` — Debug  
10. `F7`, `F8`, `F9` — Debug stepping
